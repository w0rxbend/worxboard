An ErgoDox-style split keyboard, generated from one layout file.

The exact ErgoDox key positions and 25° thumb cluster, an on-board RP2040 per half, ZMK over a TRRS cable, a memory LCD where the inner top key used to be, and USB-C on both halves. The KiCad PCB, the build123d case, the ZMK physical layout and this page all come from the same layout package.

What's in it

Exact ErgoDox layout

Switch centres, column stagger and the six-key 25° thumb cluster come from the original ErgoDox PCB, checked to 0.002 mm.

A display on each half

A Sharp memory LCD (nice!view format) replaces the top key of the inner column, behind a window in the case. Left shows ZMK status, right shows lock indicators.

On-board RP2040

No controller daughterboard: RP2040, 16 MB flash and the Corne v4.1 support circuit are assembled by JLCPCB, along with every hot-swap socket.

USB-C on both halves

The host goes into the left half. The right USB-C powers and flashes. Schottky diodes let both be plugged in at once.

Wired split, safely

ZMK's wired split over a straight TRRS cable. Power sits on Ring2 behind a polyfuse; the tip carries only resistor-limited data. A solder jumper turns cable power off.

One source of truth

A Python layout package drives the KiCad PCB generator, the build123d case, the ZMK physical layout, the docs tables and this viewer.

build it from source · uv + just + Docker
$ git clone https://github.com/w0rxbend/worxboard && cd worxboard
$ just setup          # .venv with every Python group
$ just layout-check   # layout tests + no-diff check
$ just fw             # ZMK firmware for every build.yaml row (Docker)
$ just pcb-all        # both PCBs: ERC, routing, DRC, JLC files (Docker)
$ just model          # case STEP/STL/DXF
$ just site           # this page, into _site/
